​🛠️ How to Install DontKillKupo
​Follow these steps to stop the game from closing on lobby errors!
​1. Copy the Repository Link
​First, copy this exact link to your clipboard:
https://raw.githubusercontent.com/Snakerez/WhoIsWatchingMe/main/repo.json
​2. Add the Custom Provider
​Open Final Fantasy XIV and log in to your character.
​Type /xlsettings in your chat box and press Enter.
​In the window that pops up, click on the Experimental tab.
​Find the Custom Plugin Repositories section.
​Paste the link you copied into the empty text box at the bottom.
​Click the + (plus) button to add it, then click Save and Close.
​3. Install the Plugin
​Type /xlplugins in your chat box to open the Installer.
​In the search bar at the top right, type DontKillKupo.
​Click on the plugin (it should have your custom logo!).
​Click Install.
​Note: Once installed, make sure the toggle is switched to On.
